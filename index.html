变量怎么写

          

          
变量可以直接点出来（hmi.v.名字），也可以写成字符串（hmi.set('名字', 值)）—— 两种完全等价。点上面那条插到光标处。

        

        

          

            API 速查（点一下插入）
            
          

          

          

            算术/分支/循环/模板字符串都能写：1*5、let s=0; for(…) s+=i;、`n=${n}`。

            只是「光写一个表达式」不会有输出 —— 要看得见就 hmi.log(1*5)、hmi.set('x', 1*5)，
            或者点「▶ 试运行」：它会像控制台一样把**最后一句话的值**打出来。
